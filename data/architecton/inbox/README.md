# ARCHITECTON Ω — R&D Handoff Inbox

Cette arborescence reçoit les handoffs produits par le plan R&D CÉRÉBRON.

Règles :
- un handoff n'est jamais canonique à son arrivée ;
- le fichier doit passer l'ARCHITECTON Ingest Gate ;
- une proposition d'intégration est générée sans application automatique ;
- une proposition d'avancement de phase est générée séparément ;
- seul un événement d'intégration `APPROVED` peut débloquer la phase suivante ;
- aucune ferme, IA ou modèle n'est crédité sans trace `EXEC-` vérifiable ;
- aucune publication n'est automatique.

Flux :

`R&D → inbox → Ingest Gate → Integration Proposal → décision d'intégration → Phase Advance Proposal`.

Les registres canoniques restent hors de l'inbox.
